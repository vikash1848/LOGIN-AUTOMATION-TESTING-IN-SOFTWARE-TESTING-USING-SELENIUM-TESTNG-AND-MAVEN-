
# Login Automation Suite

## Project Overview

Automated login testing using Java, Selenium WebDriver,
TestNG, and Maven.

## Features

- Valid login testing
- Invalid username and password testing
- Data-driven tests using TestNG
- Logout verification
- Page Object Model
- Explicit waits
- Automatic screenshots on test failure
- Maven test reports

## Target Website

https://practicetestautomation.com/practice-test-login/

## Requirements

- Java JDK 25
- Maven
- Google Chrome

## Run Tests

Open a terminal in the project root and run:

    mvn clean test

## Test Reports

Reports are generated in:

    target/surefire-reports/

## Failure Screenshots

Screenshots are saved in:

    screenshots/
